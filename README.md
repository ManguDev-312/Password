# Password

Password is a powerful password generator with an extremely aesthetic, modern, and intuitive design. It offers unique and exceptional versatility, so much so that it can literally be run and operated even within plain text applications like Windows Notes or TextEdit on macOS.

Main Features
Quickly create secure keys and combinations with a modern and clean user interface.

Aesthetic and minimal design for a simple and immediate user experience.

Maximum versatility: lightweight and portable, it works anywhere, even within text editors like Windows Notes and macOS TextEdit.
